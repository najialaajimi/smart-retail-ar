## Quick Start

```bash
# Clone and setup
git clone https://github.com/najialaajimi/smart-retail-ar.git
cd smart-retail-ar
git checkout smart-retail-ar-complet-final
pip install -r requirements.txt
python3 generate_qrcodes.py

# Open in Unity 2022.3.62f3 LTS
```
